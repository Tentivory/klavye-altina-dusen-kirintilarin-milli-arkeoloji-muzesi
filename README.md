# klavye-altina-dusen-kirintilarin-milli-arkeoloji-muzesi
Klavye tuşlarının altına düşen kırıntıları resmi kazı alanı, milli lezzet egemenliği ihlali ve ofis protokolü sapması sayan; silgiyi fırça, 'biraz silkerim çıkar' cümlesini kazı raporu ilan eden Müze. Gerçekten çalışır. Kırıntılar artık eserdir.
