# Klavye Altina Dusen Kirintilarin Milli Arkeoloji Muzesi

> Klavye tuşlarının altına düşen kırıntıları resmi kazı alanı, milli lezzet egemenliği ihlali ve ofis protokolü sapması sayan; silgiyi fırça, «biraz silkerim çıkar» cümlesini kazı raporu ilan eden Müze.
>
> Gerçekten çalışır. Kırıntılar artık eserdir.

## Resmi Durum Bildirimi

Bu yazılım bir şaka değildir.

Space tuşunun altı, 5 Eylül 2026 itibarıyla **1. derece milli sit alanı** ilan edilmiştir. Tuşu kaldırmak izne tabidir. İzin yoktur. İzin talebi de kırıntı sayılır.

## Ne Yapar?

`muze.py` klavyenizin altını kazmaz. Kazmış gibi yapar. Kazı raporu üretir. Eser tescil eder. Karar açıklar. Sonra damga basar.

Temizlik yapmaz. Temizlik, koleksiyonu yok etmekle eşdeğerdir.

```bash
python3 muze.py
python3 muze.py --derinlik 5
python3 muze.py --arsiv
```

`--arsiv` bayrağı, nemlenmiş bir not defterini açar. İçinde ne yazdığını sormayınız. Sordunuz.
